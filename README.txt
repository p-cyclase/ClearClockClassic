くりくろくらしっく（ClearClockClassic）
==========================================
バージョン 0.3.1

アラームとポモドーロの操作性、文字盤の見やすさを整えたバージョンです。

■ はじめに

このフォルダの中にある ClearClock.exe をダブルクリックして起動してください。
ZIP ファイルのままでは起動せず、必ず先に展開してください。

追加のソフトやライブラリをインストールする必要はありません。

■ 使い方

・時計を左ボタンでドラッグすると、好きな場所へ移動できます。
・時計を右クリックすると、設定メニューが開きます。
・メニューから大きさ、線の太さ、色、最前面表示、秒針、目盛りを変更できます。
・「アンチエイリアスを有効にする」をオンにすると、線をなめらかに表示します。初期状態はオフです。
・時計を隠したいときは、右クリックメニューから「通知領域に隠す」を選びます。
・通知領域の時計アイコンをダブルクリックすると時計を表示できます。アイコンを右クリックすると、時計の表示または終了を選べます。
・アラームとポモドーロは、時計らしいシンプルな通知だけを行う機能です。予定や作業時間を記録したり、履歴を表示したりする機能はありません。
・「アラーム／ポモドーロ」から、一回限りのアラームを設定できます。毎日繰り返すアラームではありません。時刻になると時計の色が変わり、音が1回鳴ります。時計をクリック、ドラッグ、または右クリックすると解除されます。
・「ポモドーロ開始」を選ぶと、25分の作業と5分の休憩を繰り返し、切り替わりを色と音で知らせます。作業内容や回数、経過時間を記録する機能はありません。「アラーム／ポモドーロ解除」で停止できます。
・通知時の色は初期設定では赤です。「色の設定」から、通常時・通知時ともに好きな色へ変更できます。
・終了は右クリックメニューの「終了」を選んでください。

■ 通知音を変える

sounds フォルダに、アラームとポモドーロで使う音が入っています。
alarm.wav、start.wav、goal.wav を同名の WAV ファイルに差し替えると、お好みの音に変更できます。

■ 設定の保存

終了すると、このフォルダに ClearClock.ini が作られます。
次回の起動時には、設定と表示位置が自動的に復元されます。

初期状態へ戻したい場合は、ClearClock.ini を削除してから起動してください。

■ 旧版から設定を引き継ぐ

旧版で使っていた設定を引き継ぐには、旧版フォルダ内の ClearClock.ini をこのフォルダへコピーしてから ClearClock.exe を起動してください。

新しいくりくろを終了すると、設定ファイルは現行版用の形式に保存されます。その後は新しいくりくろだけでお使いください。

■ 配布・更新情報

最新版は GitHub の Releases ページから入手してください。
