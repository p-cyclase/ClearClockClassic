# くりくろ（ClearClock）

「なでしこ」で作られたアナログ時計アクセサリ、くりくろの現代版です。旧版の処理構造と操作を保ちながら、C# と WPF に移植しています。

## できること

- 枠線、時針、分針を表示するアナログ時計
- 秒針と12本の目盛りの表示切替
- 時計の大きさ、線の太さ、色の変更
- 常に手前に表示する切替
- ドラッグによる移動
- 右クリックメニューからの設定と終了
- 前回の設定と表示位置の保存・復元

初期状態は、200 × 200 px、線幅 3 px、黒、常に手前、秒針なし、目盛りありです。

## 使い方

GitHub の **Releases** から `ClearClock.exe` をダウンロードして実行します。追加のライブラリや .NET の導入は不要です。

時計上で右クリックすると設定メニューが開きます。左ボタンでドラッグすると、表示位置を変えられます。設定は exe と同じフォルダの `ClearClock.ini` に保存され、次回起動時に復元されます。

## 配布するファイル

リリースでは `ClearClock.exe` だけを配布します。これは Windows x64 向けで、必要な .NET ランタイムを同梱した単体実行ファイルです。

## 開発

必要なものは Windows と .NET SDK 10 です。

```powershell
dotnet run
dotnet publish -c Release
```

公開用 exe は `release/ClearClock.exe` に生成されます。`release/` と `.build/` は生成物のため Git 管理しません。
