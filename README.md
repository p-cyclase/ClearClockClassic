# くりくろ

小学生の頃に「なでしこ」で作ったアナログ時計アクセサリ、ClearClock の現代版です。軽く、常に手元で時間を示す時計を目指します。

## リポジトリ構成

- `src/` — 表示と操作を担うフロントエンド
- `src-tauri/` — デスクトップアプリ本体・配布設定
- `docs/` — 仕様、デザイン、公開準備の記録
- `../legacy/` — 変更しない旧配布物（この新規プロジェクトの管理対象外）

## 開発を始めるには

1. Node.js 22 以上と Rust stable を導入します。
2. このフォルダで `npm install` を実行します。
3. `npm run tauri dev` で開発版を起動します。

> この段階では Rust が未導入のため、デスクトップアプリの起動・ビルドはまだ行っていません。

## 初期の目標

- アナログ時計の描画
- 常に手前に表示する切替
- 秒針、目盛り、色、サイズ、線幅の設定
- 設定の保存
- タスクトレイ常駐
- GitHub Releases 用の Windows 配布物

## 旧版について

旧版の配布ファイルは親フォルダの `legacy/` に、資料としてそのまま残しています。現代版の開発で旧版のファイルを変更しません。
