# くりくろくらしっく（ClearClockClassic）

「なでしこ」で作られたアナログ時計アクセサリ ClearClock の移植版です。旧版の処理構造と操作を保ちながら、C# と WPF に移植しています。

ユーザー向けの名称は「くりくろくらしっく（ClearClockClassic）」です。exe や設定ファイルなどのファイル名は、旧版との連続性を保つため `ClearClock` を使用します。

v0.2.1 は、色変更を専用の RGB 指定ウィンドウへ置き換えるバージョンです。

## 旧版から引き継いだ機能

- 枠線、時針、分針を表示するアナログ時計
- 秒針と12本の目盛りの表示切替
- 時計の大きさ、線の太さ、色の変更
- 常に手前に表示する切替
- ドラッグによる移動
- 右クリックメニューからの設定と終了
- 前回の設定と表示位置の保存・復元

## 現行版で追加・改善した要素

- アンチエイリアス（線をなめらかに表示する処理）の切替
- 旧版の `ClearClock.ini` を読み込む設定引き継ぎ
- タスクバーに表示せず、通知領域から時計を操作できる機能

初期状態は、200 × 200 px、線幅 3 px、黒、常に手前、秒針なし、目盛りあり、アンチエイリアスなしです。

## 使い方

GitHub の **Releases** から `ClearClock-vX.Y.Z-windows-x64.zip` をダウンロードします。ZIP をすべて展開し、作成された専用フォルダ内の `ClearClock.exe` を実行してください。追加のライブラリや .NET の導入は不要です。

時計上で右クリックすると設定メニューが開きます。左ボタンでドラッグすると、表示位置を変えられます。設定は exe と同じフォルダの `ClearClock.ini` に保存され、次回起動時に復元されます。

時計を隠したいときは、右クリックメニューから「通知領域に隠す」を選びます。通知領域の時計アイコンをダブルクリックすると時計を表示できます。アイコンを右クリックすると、時計の表示または終了を選べます。

## 旧版から設定を引き継ぐ

旧版で使っていた大きさ、色、表示位置などを引き継ぐには、次の操作をしてください。

1. GitHub Releases から ZIP をダウンロードし、すべて展開します。
2. 旧版が入っているフォルダから `ClearClock.ini` をコピーします。
3. 展開して作成されたフォルダ内の `ClearClock.exe` と同じ場所へ貼り付けます。
4. 新しい `ClearClock.exe` を起動します。

旧版の `ClearClock.ini` はそのまま読み込めます。新しいくりくろを終了した後は、設定ファイルが現行版用の形式で保存されます。その後は新しいくりくろだけでお使いください。

## 配布するファイル

リリースでは `ClearClock-vX.Y.Z-windows-x64.zip` を配布します。ZIP を展開すると専用フォルダが作られ、その中に `ClearClock.exe` と利用者向けの `README.txt` が入っています。

`ClearClock.exe` は Windows x64 向けで、必要な .NET ランタイムを同梱しています。設定ファイル `ClearClock.ini` もこの専用フォルダ内に保存されるため、ほかのファイルと混ざりません。

## 開発

必要なものは Windows と .NET SDK 10 です。

```powershell
dotnet run
dotnet publish -c Release
.\scripts\package-release.ps1
```

`release/ClearClock.exe` はビルド出力です。利用者に配布するものは、`dist/` に生成される ZIP です。`release/`、`dist/`、`.build/` は生成物のため Git 管理しません。
