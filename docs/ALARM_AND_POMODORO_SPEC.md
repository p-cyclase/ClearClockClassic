# アラーム・ポモドーロ機能仕様書

## 目的

くりくろくらしっくの時計表示を変えずに、時刻または時間の経過を知らせる機能を追加する。

アラームとポモドーロは利用目的と状態を別に持つ機能として扱う。一方、通知音の再生と時計の色変更は共通の処理を利用する。両機能は同時に動かさない。

この文書は、アラームとポモドーロの実装仕様を扱う。

## 共通方針

通知は追加のダイアログや常時表示の文字を用いず、時計の線全体の色と通知音で伝える。時計の円の内側は塗りつぶさず、透明な時計という見た目を維持する。

| 項目 | 内容 |
| --- | --- |
| 通常色 | 「色の設定」で設定する、枠・針・目盛りの色 |
| 通知時の色 | アラーム発生中、およびポモドーロの休憩中に使用する色。初期値は赤（`#FF0000`） |
| 色の反映範囲 | 枠・針・目盛りのすべて |
| 通知音 | exe と同じフォルダ内の `sounds` フォルダから、通知の種類に対応する WAV ファイルを再生する |

配布 ZIP には、次の WAV ファイルを `sounds` フォルダ内に標準の通知音として同梱する。利用者は同名の WAV ファイルへ差し替えることで、通知音を変更できる。

| ファイル | 用途 |
| --- | --- |
| `sounds/alarm.wav` | アラームの通知時 |
| `sounds/start.wav` | ポモドーロの作業開始時 |
| `sounds/goal.wav` | ポモドーロの25分間の作業終了・休憩開始時 |

WAV ファイルがない、または再生できない場合でも、アプリケーションを終了させず、色の変更による通知は継続する。

## 共通処理

アラームとポモドーロは、次の処理を共通して利用する。

| 処理 | 内容 |
| --- | --- |
| 通知音の再生 | 通知の種類に対応する WAV ファイルを1回だけ再生する |
| 通知色の適用 | 時計の描画色を通知時の色へ切り替えて再描画する |
| 通常色の復帰 | 時計の描画色を通常色へ戻して再描画する |
| 通知音ファイルの取得 | exe と同じフォルダ内の `sounds` フォルダから WAV ファイルを取得する |

共通処理は通知の見た目と音だけを担当する。アラームの確認待ち状態、およびポモドーロの作業・休憩の進行状態は、それぞれの機能が管理する。

アラームとポモドーロは同時に動かさない。どちらかが有効な間は、もう一方を開始する操作をメニューに表示しない。これにより、時計が同時に複数の通知状態を表したり、利用者の操作によって有効な機能が意図せず解除されたりすることはない。

通知領域に時計を隠していても、アラームとポモドーロの時間計測は継続する。アラームの発生、またはポモドーロによる色の切り替え時には、時計を自動的に再表示する。アプリケーションを完全終了した場合は、アラームとポモドーロをともに解除する。

## メニューでの状態表示

右クリックメニューの「アラーム／ポモドーロ」は、現在有効な機能と実行できる操作を状態ごとに表示する。残り時間の表示やカウントダウンは行わない。

| 状態 | 表示する項目 |
| --- | --- |
| 未設定 | `アラーム設定`、`ポモドーロ開始` |
| アラーム設定済み | `アラーム設定（HH:MM）`、`アラームを解除` |
| ポモドーロ作業中 | `ポモドーロ：作業中`（選択不可）、`ポモドーロを停止` |
| ポモドーロ休憩中 | `ポモドーロ：休憩中`（選択不可）、`ポモドーロを停止` |

アラーム設定済みの「アラーム設定（HH:MM）」を選ぶと、時刻を変更できる。ポモドーロを開始するには、設定済みのアラームを先に解除する。アラームを設定するには、実行中のポモドーロを先に停止する。

アラームが通知中の場合は、時計本体に対する操作で確認済みにするため、メニューに通知中の状態や専用の確認操作は表示しない。

## アラーム機能

### 役割

利用者が指定した時刻になったことを、一回だけ知らせる。

### 通知時の動作

指定時刻になると、通知音を1回再生し、時計の描画色を通知時の色へ切り替える。追加のウィンドウは表示しない。

通知時の色は、時計本体に対する左クリック、左ドラッグ、または右クリックによって確認済みになるまで維持する。確認済みになると、時計を通常色へ戻し、そのアラーム自体を無効にする。時計が通知領域に隠れている場合は、通知の発生時に時計を再表示する。

時計の移動操作も確認済みの操作として扱う。アラームを確認するためだけのメニュー項目やダイアログは設けない。

### 状態

| 状態 | 時計の色 | 動作 |
| --- | --- | --- |
| 設定なし / 待機中 | 通常色 | 指定時刻を待つ |
| 通知中 | 通知時の色 | 音を1回再生済み。時計への左右どちらかの操作を待つ |
| 確認済み | 通常色 | 通知を終了する |

### 設定

アラームは1件だけ設定できる。未設定時は右クリックメニューの「アラーム／ポモドーロ」内の「アラーム設定」で、時（0〜23）と分（0〜59）を指定する。設定ダイアログを開いたときの初期時刻は、現在時刻の3分後とする。日付をまたぐ場合は時刻を0時台へ繰り上げる。設定済みの場合は「アラーム設定（HH:MM）」から時刻を変更でき、その設定時刻を初期値として表示する。指定時刻がすでに過ぎている場合は翌日に通知する。

設定済みのアラームは、右クリックメニューの「アラームを解除」で無効にできる。

アラームの時・分および通知中の状態は `ClearClock.ini` に保存しない。アプリケーションを終了すると、設定済みのアラームは解除される。

通知時の色は通常色と共通の「色の設定」ウィンドウで指定し、`ClearClock.ini` に保存する。既存の設定値の後ろへ通知時の色を追加するため、旧版およびこれまでの現行版の INI はそのまま読み込める。

## ポモドーロ機能

### 役割

作業と休憩を一定時間ごとに繰り返し、その切り替わりを時計の色と通知音で知らせる。

### 時間と色

ポモドーロは、次の2段階を繰り返す。

| 段階 | 時間 | 時計の色 |
| --- | --- | --- |
| 作業 | 25分 | 通常色 |
| 休憩 | 5分 | 通知時の色 |

休憩が終わると、時計の色を通常色へ戻して次の25分間の作業へ移る。アラームのような確認待ち状態は作らず、ポモドーロは時間経過に従って自動的に進行する。

開始からの実経過時間を基準に、30分（作業25分・休憩5分）ごとの現在段階を算出する。PCがスリープしていた時間も経過時間として扱い、復帰後はその時点の段階へ直ちに追いつく。

### 状態

| 状態 | 時計の色 | 動作 |
| --- | --- | --- |
| 停止中 | 通常色 | 時間を進めない |
| 作業中 | 通常色 | 25分を計測する |
| 休憩中 | 通知時の色 | 5分を計測する |

通知領域に隠れている場合、作業と休憩の切り替え時に時計を再表示する。

### 通知音

ポモドーロを開始し、作業へ入るときは `sounds/start.wav` を1回再生する。休憩から次の作業へ切り替わるときも、`sounds/start.wav` を1回再生する。

作業から休憩への切り替え時には `sounds/goal.wav` を1回再生する。

### 開始と解除

未設定時は右クリックメニューの「アラーム／ポモドーロ」内の「ポモドーロ開始」で、25分間の作業を開始する。ポモドーロの実行中は、開始操作の代わりに「ポモドーロ：作業中」または「ポモドーロ：休憩中」を選択不可の状態表示として示す。

ポモドーロは「ポモドーロを停止」で解除する。停止した場合、作業・休憩の経過時間は破棄する。次に開始するときは、必ず新しい25分間の作業から始める。
