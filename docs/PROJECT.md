# プロジェクト方針

## 名前

- 表記: くりくろ
- 英字表記: Kurikuro
- 由来: 旧版「くりくろ（ClearClock）」を受け継ぐ

## 技術方針

Tauri 2 と TypeScript を使い、Windows で軽く動作するデスクトップアプリとして作る。表示部分は Web 技術で実装し、ネイティブ機能（常に手前、タスクトレイ、設定保存、配布）は Tauri が担う。

## 旧版との関係

`../legacy/` は配布当時の資料であり、変更・移動・自動整形をしない。現代版は `clearclock/` 内に独立して実装する。

## 最初のリリース範囲

1. 円形のアナログ時計
2. 秒針・目盛りの表示切替
3. 色、サイズ、線幅の設定
4. 常に手前に表示する切替
5. タスクトレイと終了操作
6. Windows 向けインストーラーとポータブル配布の検討
