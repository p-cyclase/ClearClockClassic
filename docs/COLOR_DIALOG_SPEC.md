# 色設定ウィンドウ仕様書

## 目的

右クリックメニューの「色の設定」を選んだとき、くりくろくらしっく専用の小さな色設定ウィンドウを表示する。

通常時の色と通知時の色を、同じウィンドウで詳細に指定できるようにする。時計の常時表示や通常操作を複雑にしないため、このウィンドウは「色の設定」を選んだときだけ表示する。

## 対象範囲

対象は、時計ウィンドウの右クリックメニューから開く通常時・通知時の色設定機能だけとする。

時計の描画方法、設定ファイルの保存形式、右クリックメニュー内の他の項目、通知領域の動作は変更しない。

## 表示内容

ウィンドウのタイトルは「色の設定」とする。通常時と通知時の設定ブロックを縦に並べる。

| 要素 | 内容 |
| --- | --- |
| 通常時 | R / G / B を 0 から 255 の整数で入力する欄と、右側の色見本 |
| 通知時 | R / G / B を 0 から 255 の整数で入力する欄と、右側の色見本 |
| 色見本 | 各設定ブロックの3つの入力欄と上端・下端を揃える。白でも確認できるよう、周囲に薄い灰色の枠線を付ける。 |
| OK | 両方の入力値を確定してウィンドウを閉じるボタン |
| キャンセル | どちらの色も変更せず、ウィンドウを閉じるボタン |

標準的な Windows の小さな設定ダイアログに近い、簡潔な配置とする。色相環、パレット、履歴、プリセットなどの補助機能は設けない。

## 開いたときの状態

通常時・通知時の各入力欄は、その時点で時計に設定されている色を初期値として表示する。色見本もそれぞれ同じ色で表示する。

設定ファイルがない場合、通常時の色は黒、通知時の色は赤（RGB 255, 0, 0）を初期値とする。

## 入力と確定

- RGB の各値は 0 から 255 までの整数だけを有効とする。
- 各ブロックの入力値が有効な間は、対応する色見本をその値に合わせて更新する。
- どちらかに無効な入力値がある状態では、OK による確定は行わない。
- OK を選ぶと、通常時と通知時のRGB値を確定する。時計は通常時の色で直ちに再描画する。
- キャンセル、またはウィンドウ右上の閉じる操作では、変更前の色を維持する。

## 白の扱い

白（RGB 255, 255, 255）は、そのまま確定できるようにする。色見本も指定した白を表示する。

これは旧版からの変更である。旧なでしこ版では、白を指定すると透明として扱われるため、代わりに RGB 255, 255, 254 を設定していた。現行の WPF 版では、透明なウィンドウ背景と時計の線の色が別に扱われる。白い線は不透明に描画できるため、この回避処理は不要である。

## 設定ファイルとの関係

OK で確定した通常時の色と通知時の色は、アプリケーション終了時に `ClearClock.ini` へ保存する。通知時の色は既存項目の後ろへ追加し、旧版 `ClearClock.ini` の読み込み互換性を保つ。

## 実装前提

この文書の内容は、現行版の専用色設定ウィンドウに実装されている。
