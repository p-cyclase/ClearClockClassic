# 色変更ウィンドウ仕様書（予定）

## 目的

右クリックメニューの「色の変更」を選んだとき、Windows 標準の色選択ダイアログの代わりに、くりくろくらしっく専用の小さな色変更ウィンドウを表示する。

色を詳細に指定できることを保ちつつ、表示までの待ち時間を抑える。時計の常時表示や通常操作を複雑にしないため、このウィンドウは「色の変更」を選んだときだけ表示する。

## 対象範囲

対象は、時計ウィンドウの右クリックメニューから開く色変更機能だけとする。

時計の描画方法、設定ファイルの保存形式、右クリックメニュー内の他の項目、通知領域の動作は変更しない。

## 表示内容

ウィンドウのタイトルは「色の変更」とする。

| 要素 | 内容 |
| --- | --- |
| 赤 | 0 から 255 までの整数を入力する欄 |
| 緑 | 0 から 255 までの整数を入力する欄 |
| 青 | 0 から 255 までの整数を入力する欄 |
| 色見本 | 入力中の RGB 値による色を表示する領域。白でも確認できるよう、周囲に薄い灰色の枠線を付ける。 |
| OK | 入力値を時計の色として確定し、ウィンドウを閉じるボタン |
| キャンセル | 時計の色を変更せず、ウィンドウを閉じるボタン |

標準的な Windows の小さな設定ダイアログに近い、簡潔な配置とする。色相環、パレット、履歴、プリセットなどの補助機能は設けない。

## 開いたときの状態

RGB の各入力欄は、その時点で時計に設定されている色を初期値として表示する。色見本も同じ色で表示する。

## 入力と確定

- RGB の各値は 0 から 255 までの整数だけを有効とする。
- 入力値が有効な間は、色見本をその値に合わせて更新する。
- 無効な入力値がある状態では、OK による確定は行わない。
- OK を選ぶと、RGB 値を時計の枠線・針・目盛りの色へ反映し、時計を直ちに再描画する。
- キャンセル、またはウィンドウ右上の閉じる操作では、変更前の色を維持する。

## 白の扱い

白（RGB 255, 255, 255）は、そのまま確定できるようにする。色見本も指定した白を表示する。

これは旧版からの変更である。旧なでしこ版では、白を指定すると透明として扱われるため、代わりに RGB 255, 255, 254 を設定していた。現行の WPF 版では、透明なウィンドウ背景と時計の線の色が別に扱われる。白い線は不透明に描画できるため、この回避処理は不要である。

## 設定ファイルとの関係

OK で確定した色は、既存どおりアプリケーション終了時に `ClearClock.ini` へ保存する。保存形式および旧版 `ClearClock.ini` の読み込み互換性は変更しない。

## 実装前提

この文書は実装予定の仕様であり、現行版の色変更機能は Windows 標準の色選択ダイアログを使用している。実装時には、この文書と上位設計書の記述を整合させる。
