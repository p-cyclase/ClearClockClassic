# 時計描画仕様書

## 目的

くりくろくらしっくの文字盤を、時計として見やすく、旧版に近い簡素な線画として描画するための下流仕様を定める。

この文書は枠線・針・目盛りの見た目を対象とする。時計の操作、設定ファイル、通知機能、および配布方法は対象外とする。

## 文字盤の基本方針

- 文字盤は塗りつぶさず、円形の枠線だけを描画する。
- 針と目盛りは枠線と同じ色、同じ線幅で描画する。
- 線の両端は丸くする。
- 目盛りは、文字盤の枠線に接する短い12本の線とする。

## 目盛り

### 表示

- 「目盛りを表示する」が有効なときだけ、12時から時計回りに30度間隔で12本を描画する。
- 目盛りの外側の端は、文字盤の枠線に接する位置に置く。
- 目盛りは枠線の内側へ向かって伸ばす。枠線から離れた位置に浮かせない。

### 太さと長さ

- 目盛りの線幅は、枠線・針と同じ設定値を使用する。
- 目盛りの長さは、時計の大きさを基準に決める。線幅を大きくしても、目盛りそのものの長さを短くしてはならない。
- 線幅を変更したときも、丸い線端が枠線に重なって目盛りが見えなくならないだけの長さを確保する。
- 通常の大きさと太さ（100〜300 px、線幅 2〜5 px）では、すべての目盛りを枠線から明確に見分けられる状態にする。

### 見た目

- 目盛りは長くしすぎず、旧版に近い控えめな短さを保つ。
- 太い線幅でも、枠線の一部ではなく独立した目盛りとして見えることを優先する。
- アンチエイリアスのオン・オフによって、目盛りの位置・本数・長さの設計は変えない。

## 確認項目

次の組み合わせで、「目盛りを表示する」を有効にして見た目を確認する。

| 時計の大きさ | 線幅 |
| --- | --- |
| 100 px | 2 px / 3 px / 5 px |
| 200 px | 2 px / 3 px / 5 px |
| 300 px | 2 px / 3 px / 5 px |

各組み合わせで、枠線に接した12本の目盛りが確認できることを合格条件とする。
