# assets の管理方針

`assets` は、くりくろくらしっくの実行ファイルや配布 ZIP に含める素材を管理するフォルダである。

## 管理対象

次の素材は Git で管理する。

| 場所 | 内容 |
| --- | --- |
| `ClearClock.ico` | 実行ファイルと通知領域に使う時計アイコン |
| `sounds/alarm.wav` | アラーム通知音 |
| `sounds/start.wav` | ポモドーロの作業開始音 |
| `sounds/goal.wav` | ポモドーロの作業終了・休憩開始音 |

音声機能を実装する際は、これらの WAV ファイルを配布 ZIP 内の `sounds` フォルダへ配置する。

## 管理しないもの

音声編集のプロジェクト、元音源、試聴用ファイル、画像の作業データなど、配布物に含めない素材は `assets/work` に置く。このフォルダは Git 管理しない。

一時ファイルや OS が作成するファイルも Git 管理しない。

## 素材の更新

- 配布用素材を差し替えるときは、同じファイル名と形式を維持する。
- WAV の長さや内容は変更してよいが、通知機能の実装後は実際の配布 ZIP で再生を確認する。
- `assets` の素材を変更した場合は、実行ファイルと配布 ZIP を再生成する。
